# Published 2-SAT checkpoint: development-only causal-report pilot

Contract recorded 2026-10-15, before valid-formula inference for this pilot. This is a development study, not the protected final evaluation and not a replication of the original Goodfire model. Changes after outcomes must be separately versioned and labelled exploratory.

## Frozen source and task

- Palumbo et al., *Validating Mechanistic Interpretations: An Axiomatic Approach*, ICML 2025, arXiv:2407.13594v2; repository https://github.com/nilspalumbo/axiomatic-validation, commit `35d1e4105265ab0ca74bc7daf9371fc8f82bba81`.
- Checkpoint `models/layers_2_heads_1_4_1M/900.pth`, SHA256 `d587446c64b7a8d68de93808ccf84a84364b85dcaf2149b8983b77895e24046d`.
- Execute the original model class ASTs, without changing their computation. `model.py` SHA256 `7555e1f2f27546225397aa12de4fde1f6c903e9804766de477fe4c02770691ea`; CPU PyTorch 2.1.2, float32, two threads, eval mode, no gradient/training.
- Canonical grammar: five variables, exactly ten clauses; each clause contains two distinct variables, in increasing variable-index order, independently positive or negative. There are 40 clause types. Repeated clauses are allowed. Tokens are `(`, literal, literal, `)` repeated ten times, then `:`. Label tokens are not model inputs.
- Primary population: 4,096 distinct initially satisfiable formulas generated by drawing ten canonical clauses independently and uniformly, rejecting UNSAT and exact duplicate clause sequences. NumPy PCG64 seed `2026101511`. This is a conditional development distribution, not the original paper's test distribution.
- The first 3,072 generated origins are development fit origins; the remaining 1,024 are development assessment origins. Entire origins remain in one split. These are not protected test cases. No original training or interpretation dataset is opened.

## Frozen reports, actions, targets

The published report is the final-position second-block post-ReLU activation at units
`[10,29,36,41,48,55,77,81,96,150,185,189,195,201,224,231,245,261,291,304,317,326,334,374,380,411,416,435,450,482,490,492,495,499]`, thresholded at `>=0.5`. These IDs are transcribed from output cell 77 of the distributed `interpretation.ipynb` (SHA256 `5410cc7cc28e28d303906cd8879bf95c161cda669c01d608014d7644bc742582`), not reselected.

Comparison reports are all 34 original activation magnitudes; 34 distinct random units from the complement of the published units, selected once with PCG64 seed `2026101512`, each as threshold bits and as magnitudes; and the exact 32-valuation truth table. Random-unit controls match dimension and decoder capacity, not activation distribution. The full 32-vector of violated-clause counts supplies an exact symbolic positive control and is not a free neural feature. No neuron selection, activation-threshold tuning, or quantizer search is permitted in this pilot.

Each action is `(slot, old_clause, new_clause)` with the actual old clause stated and a different canonical replacement. The response target is whether the edited formula is SAT, evaluated exactly on all 32 valuations. Each origin has 390 applicable action rows. Predictors receive only their report and that row's action; they never receive original tokens, post-edit activations, or other slots' old clauses.

Each action-selection decision is restricted to the 39 replacements of one stated `(slot, old_clause)`, with the goal of finding an edit that makes the initially SAT formula UNSAT. Decisions are made independently per slot. Combining all ten action menus would reveal the complete formula; this is excluded from the report-only predictor contract. Abstention and reachability will be distinguished.

## Primary collision search

Search the whole development bank for pairs with identical **nonzero** published 34-bit reports and identical action context, but different exact edited SAT labels. Both originals must have checkpoint argmax equal to the SAT token. Every published-unit activation of both originals must be at least `1e-4` away from 0.5, and both original full-vocabulary prediction margins must exceed `1e-4`.

Candidate ordering is deterministic: report integer, slot, old clause, new clause, then origin index. Keep the first 128 distinct candidate pairs, then evaluate their edited inputs. The primary witness is the first candidate whose two edited checkpoint argmax labels equal their exact semantic labels, with full-vocabulary margin above `1e-4`. Retain all candidate outcomes. Do not expand this search adaptively if it fails. Numerical guards are robustness diagnostics, not analytic floating-point error bounds.

Replay any accepted witness in a separate process from saved tokens and frozen weights. Recompute the semantic labels independently with Python Boolean arithmetic. Record input tokens, original/edited 16 logits, original 34 activations and bits, action, counts/truth tables, hashes, and threshold/margin distances. A witness certifies failure of a deterministic decoder of the stated finite report and action under the new edit-response contract. It does not refute the authors' existing claims or establish a theorem about exact-real transformer arithmetic.

## Fixed predictive and decision comparison

For each fit origin and slot, choose exactly two distinct replacements uniformly with PCG64 seed `2026101513` (61,440 fit rows). Assess all 390 actions for every assessment origin (399,360 rows). Fit each report with the same `HistGradientBoostingClassifier(max_iter=100, max_leaf_nodes=15, learning_rate=0.08, l2_regularization=1.0, max_bins=63, early_stopping=False, random_state=2026101514)`. Encode slot, old clause and new clause as one-hot vectors of lengths 10,40,40. A context-only model is also reported. No hyperparameter search or second fit after observing assessment outcomes.

Report response accuracy, balanced accuracy, AUROC, log loss, and per-origin error. For each of 10,240 assessment menus, select the replacement with greatest predicted UNSAT probability, ties by lowest clause ID. Report success over all menus and conditional on a valid UNSAT-producing replacement existing; report abstention at predicted UNSAT probability below 0.5 separately. All semantic labels, including failures, remain in the denominators. Provide paired differences at the origin level. These development comparisons are descriptive; they cannot establish a protected confirmatory generalization claim.

Evaluate actual checkpoint correctness for the first 128 accepted candidate edits and for a deterministic subset of 128 assessment origin-slot menus (PCG64 seed `2026101515`), covering selected actions for every report model. Do not condition headline predictive metrics on checkpoint correctness. Report the checkpoint-correct stratum separately when available.

## Compatibility and failure handling

Before substantive interpretation, verify strict parameter loading, grammar/token round trips, exact oracle agreement between vectorized counts and an independent 32-assignment Boolean loop, and equality of whole-model versus explicit three-stage decomposition on the first eight development origins. Original source and checkpoint remain unchanged. Persist errors and runtime receipts.

The already-completed smoke check used one all-zero invalid-grammar input and reported only shapes/finite values; it did not inspect valid task responses. This contract's prior information includes the published notebook's original results and neuron list.

Stop after this pilot and report to the parent campaign before any larger or protected confirmation. If there is no nontrivial initially-SAT witness, or improvements are absent, retain that failure. Claims of novelty concern any demonstrated mechanism/decision consequences of discarded amplitude information, not the classical fact that clause-violation counts close under replacements, nor the paper's already-studied component/prefix substitutions.
