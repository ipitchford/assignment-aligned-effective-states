# Pre-fit implementation choices

This implements only the admitted cached comparison. The fixed estimator and all defaults are recorded before fitting. No native model module is imported, no model weights are loaded, and no formula is generated. All inputs are hashes of already opened caches.

Rows use saved query order with repair then neutral, retaining duplicate native inputs. One predictor per source unit fits only selected clipped fit rows. A single predict_proba call per fitted unit covers its selected fit and assessment rows in unchanged order; the report then uses the four specified scopes. The positive class is explicitly located in classes_; strict probability >0.5 defines the prediction. Fit failures and nonfinite outputs produce NA for that unit, with no retries. Missing/one-class fit cases consume their unit slot without releasing another fit.

The complete fitted sklearn object is serialized with pickle protocol 5. A companion NPZ/JSON export retains each predictor's node arrays, categorical bitsets, bin thresholds, initial prediction, class order and feature metadata. Pickles are locally produced artifacts; only load them in a trusted environment. Python implementation files and installed compiled-module hashes are archived before fitting. Peak memory is process-wide ru_maxrss, converted from native units on this platform; it includes interpreter and libraries.

Paired uncertainty uses the exact saved 2,000 multiplicity vectors over the exact saved origin IDs. Confusion tables aggregate both actions and every unit for each origin before multiplication. Arithmetic uses float64, with missing native classes or failed predictors producing NaNs that propagate through duplicated-assignment means and the macro. The unchanged structured bootstrap is recomputed from cached labels/predictions and required to match the retained bootstrap before interpreting the comparison. No resampling or refitting occurs.

Synthetic tests check feature offsets, exact float conversion, strict probability ties, class-support/NA propagation, duplicate assignment averaging, interval-support boundary and the outcome-neutral interpretation rules. They fit no estimator and inspect no empirical outcomes. The run lock prevents a second fit/assessment. Execution writes per-unit records as fits proceed, preserves any exception and stops after the single report.
