# Assignment-Aligned Effective States in a 2-SAT Transformer

Version 4.8.0 candidate. Anonymous. DOI 10.5281/zenodo.23454637 is reserved;
consult `STATUS.md` for verified availability.

Read `paper.pdf` and `supplement.pdf` first. Editable Markdown and generated
LaTeX are included. `build_public.py` documents the rendering pipeline.
`AI_INDEX.md` provides a machine entry point; `claim_evidence_map.json` is a
research navigation aid, not an independent verification certificate.

The research distinguishes semantic assignment truth, native threshold events,
learned-basis prediction, numerical rank and readout reconstruction. The finite
study does not establish universal causal semantic recovery or unrestricted
cross-checkpoint generality.

## Reproduce the distributed evidence

Install the three separately specified environments in `environments/`, then run:

```sh
python reproduce.py --output /absolute/new/output \
  --upstream-directory /absolute/external/sources \
  --analysis-python /absolute/analysis/python \
  --scientific-python /absolute/scientific/python \
  --native-python /absolute/native/python
```

The output must be new and outside the extracted archive. The runner checks
exact external source hashes before copying them into its disposable workspace.
Retrieve them explicitly with `python setup_external.py --output /absolute/external/sources`.
Replay itself performs no network requests. These adapted architecture sources
are not redistributed because their inherited licence chain was not established;
public retrieval is not proof of redistribution rights. The runner checks
the complete distributed inventory before and after execution. It targets
**18 stages**: 12 JSON-result stages, one complete-bank native comparison, and
five supporting numerical/exact stages. Read the resulting receipt for actual
success; a configured target is not a result. The Python access hook covers
top-level stages, not every nested process or native I/O; it is not an OS sandbox.

Five image-dependent historical stages are unavailable. A separate publisher
replay of the original larger input set does not make those inputs public.
See `PUBLIC_PACKAGE_SCOPE.md` and `ASSURANCE.md`. The public margin audit checks
5,390 available conditions; 17 historical pickle hash checks are unavailable.
Historical pickle sizes are metadata, not byte validation. One diagnostic log
is also unavailable. All distributed scientific arrays retain exact hashes.

`prospective/README.md` describes the additional source-style bank and portable
native comparison. It is separate from the historical 18-stage runner.
