# Assurance boundaries

Analytic deductions, finite arithmetic checks, checkpoint execution, statistical
diagnostics and editorial review are distinct evidence classes. No theorem
prover has verified this release. AI-assisted assessment is not external human
peer review, and replay on the publisher's host is not independent replication.

The public runner targets 18 redistributed stages; five historical image stages
are unavailable. Public replay receipts, rather than this document, establish
which stages actually passed. Original private replay of a larger input set does
not make its omitted inputs accessible to readers.

The margin public adapter checks 5,390 available conditions. Seventeen original
pickle hash checks are unavailable. Pickle byte counts are historical metadata,
not validation of undistributed bytes. Exact numeric arrays remain available.
The separate task-policy negative-score screen verifies two available manifest
members and reports one additional unavailable original pickle byte identity.
Native replay also requires three exact hash-pinned external source files, fetched
explicitly by the reader; these are not bundled and retrieval is not rights clearance.

The presentation map resolves only pinned editorial derivatives. It does not
claim that the complete historical byte inventory is still distributed.
